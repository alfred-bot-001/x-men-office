# Compliance AI Agent Management Platform - Demo

## 技术栈
- 纯 HTML5 + CSS3 + JavaScript (ES6+)
- Tailwind CSS (CDN)
- Chart.js (CDN)
- 零构建步骤，直接部署到任意静态服务器

## 部署方法
直接将所有文件上传到静态服务器，访问 `index.html` 即可。

## 功能模块
1. **Agent 管理** - 创建/编辑 AI Agent，配置技能和工作模式
2. **工作列表** - Agent 状态看板（空闲/忙碌/需审批）
3. **工作详情** - Agent 思维链展示 + 人工确认节点
4. **工作量 Dashboard** - KPI 卡片 + 图表分析
5. **Skill 管理** - SOP 上传解析 + 可视化流程编辑器
